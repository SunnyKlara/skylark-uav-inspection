# 飞行安全检查单

> 这份是**要打印出来带到场地**的。不是参考文档，是操作清单。
> 每次飞行按顺序逐项打勾。跳步的代价是炸机或伤人。
>
> 适用：Pixhawk 6C + 多旋翼 + 机载电脑（Offboard 自主巡检）
> 最后更新：2026-07-27

---

## 铁律（任何情况下都不违反）

1. **桨叶是最后装的，也是最先拆的。** 任何软件调试、参数修改、固件刷写，桨叶必须在机外
2. **遥控器永远开着，永远在手边。** 自主飞行时人是最后一道保险，不是观众
3. **先仿真，再地面，再系绳，再自由飞。** 四级递进，不跳级
4. **没有 SD 卡不起飞。** 没有 `.ulg` 日志的飞行等于没飞 —— 出问题无法复盘，成功也无法写进论文
5. **改了任何参数或固件，回到 S2 地面联调重新验证。** 不允许"改一个参数直接飞"
6. **飞控的自主失效保护优先级最高。** 机载电脑、ROS 2 节点、地面站都不能否决它

---

## A. 出门前（在家做，约 20 分钟）

### A1 软件状态

- [ ] `flight/params/` 里有当前机架的 `.params` 基线快照，且 `CHANGELOG.md` 与实际一致
- [ ] 固件版本确认：QGC 概要页显示的版本 == `flight/VERSIONS.md` 里锁定的版本
- [ ] 如果改过 `dds_topics.yaml`，确认刷的是自编译固件而非官方固件（见 `SERIAL_BUDGET.md` §5）
- [ ] SITL 里跑过一遍本次要执行的任务 YAML，全程无异常
- [ ] 机载电脑上的 ROS 2 工作区已 `colcon build` 成功，无编译警告遗留

### A2 电池

- [ ] 飞行电池已充满，静置电压正常（4S 约 16.8 V，6S 约 25.2 V）
- [ ] 电池无鼓包、无破损、插头无氧化
- [ ] 至少准备 2 组电池 + 1 组遥控器电池
- [ ] 电池监控参数已配（`BAT1_N_CELLS` 等），QGC 显示的电压与万用表实测一致（误差 <0.2 V）

### A3 装备清单

- [ ] 遥控器（已充电，已绑定）
- [ ] 笔记本 + 数传（QGC 能连上）
- [ ] 备用桨 ×1 套
- [ ] 六角扳手 / 螺丝刀
- [ ] 系绳（S3 首飞阶段必带）
- [ ] 灭火毯或沙桶（锂电池起火用水无效）
- [ ] 急救包

### A4 场地与法规

- [ ] 场地确认：空旷、无人群、无高压线、无机场净空区
- [ ] 天气确认：风速 < 5 m/s、无降水、能见度良好
- [ ] 按当地规定完成必要的空域报备/实名登记
- [ ] 已告知现场其他人：无人机要飞，请退到安全距离外

## B. 到场后 —— 上电前（约 10 分钟）

- [ ] 机架螺丝逐个手检，无松动
- [ ] 电机座固定牢固，手扭电机无晃动
- [ ] **桨叶未安装**
- [ ] 所有线束固定，无垂落、无与桨盘干涉
- [ ] 按 `WIRING_6C.md` §10 的接线自检清单逐项确认
- [ ] **SD 卡已插入飞控**
- [ ] GPS 模块箭头朝机头，天线朝上无遮挡
- [ ] 机载电脑的独立 BEC 已接，**未从飞控取电**
- [ ] 万用表确认 POWER1 输入电压在 4.9–5.5 V

---

## C. 上电后 —— 装桨前（约 15 分钟）

上电顺序：**先接飞控供电，再开机载电脑，最后开遥控器**。

### C1 基础状态

- [ ] 蜂鸣器自检音正常，无报错音
- [ ] QGC 连接成功，无红色告警
- [ ] 固件版本与预期一致
- [ ] IMU 温度已稳定（6C 有 IMU 加热，冷启动需等 1-2 分钟）
- [ ] 罗盘朝向正确：转动机体，QGC 里的机头指向随之转动且方向一致
- [ ] GPS 定位：卫星数 ≥ 12，`eph` < 1.5 m（室外空旷处，通常需 1-3 分钟）
- [ ] 电池电压 QGC 显示值与万用表一致

### C2 遥控与失效保护

- [ ] 遥控器所有通道校准过，杆量方向正确
- [ ] 飞行模式开关逐档切换，QGC 显示的模式与预期一致
- [ ] **RTL 开关位置已确认，且我能不看手闭眼拨到它**
- [ ] 失效保护验证：关闭遥控器，QGC 应报 RC 链路丢失并触发预设动作。**测完重新开机**
- [ ] 低电量失效保护参数已配（`BAT_LOW_THR` / `BAT_CRIT_THR` / `COM_LOW_BAT_ACT`）
- [ ] 地理围栏已设（`GF_MAX_HOR_DIST` / `GF_MAX_VER_DIST`），范围小于场地边界

### C3 机载电脑链路（Offboard 飞行必检）

- [ ] `ros2 topic list` 能看到 `/fmu/out/*` 话题
- [ ] `ros2 topic hz /fmu/out/vehicle_local_position` 频率稳定，符合 `SERIAL_BUDGET.md` 的预期值
- [ ] `ros2 topic echo /skylark/flight_health` 中 `companion_link_ok == true`
- [ ] `ros2 topic echo /skylark/flight_health` 中 `failsafe_active == false`
- [ ] **三重中止通道逐个实测**：
  - [ ] 遥控器切换飞行模式 → QGC 显示模式改变
  - [ ] QGC 界面切换飞行模式 → 生效
  - [ ] `ros2 service call /skylark/abort_mission ...` → 返回 success
- [ ] `AbortMission` 服务的响应延迟 < 500 ms

### C4 电机测试（**桨叶仍未安装**）

- [ ] 安全开关已解除（长按 1 秒）
- [ ] QGC → Actuators 页面，逐个点动电机
- [ ] 电机编号与 `Airframe Reference` 一致（MAIN1..4 对应 I/O PWM OUT 的 IO_CH1..4）
- [ ] **每个电机的转向逐个确认**，与机架图一致
- [ ] 电机运转平顺，无异响、无卡顿
- [ ] 上锁，断电

> 电机顺序或转向错了直接装桨起飞 = 立刻翻扣打人。这一步是整份清单里最不能省的。

---

## D. 装桨（约 5 分钟）

- [ ] **确认已上锁且安全开关已锁定**
- [ ] 按机架图安装正反桨（CW/CCW 别装错）
- [ ] 每个桨的螺母/快拆扣紧到位，手拉不脱
- [ ] 桨叶无裂纹、无缺口、无变形
- [ ] 手动缓慢转动每个桨，确认不刮碰机架和线束
- [ ] 所有人退到 5 米外

---

## E. 起飞前最后 60 秒

- [ ] 我站在飞机**侧后方**，不在桨盘平面内
- [ ] 遥控器在手，RTL 开关位置已确认
- [ ] QGC 无告警，GPS 锁定良好
- [ ] 电池电压充足
- [ ] 现场无人进入飞行区
- [ ] 大声报出："准备起飞"，等所有人回应

---

## F. 首飞（S3 第一阶段：系绳低空）

- [ ] 系绳已连接，长度限制在 2-3 m
- [ ] **手动模式**（Stabilized / Altitude）起飞，不用自主模式
- [ ] 缓慢加油门至离地 0.5 m，悬停 10 秒
- [ ] 观察：是否自行偏移？是否有异常振动？是否有异响？
- [ ] 逐轴测试：小幅度俯仰、横滚、偏航，响应方向正确
- [ ] 降落，上锁，**检查电机温度**（烫手说明有问题）
- [ ] 下载 `.ulg`，用 `flight_review` 检查振动谱与姿态跟踪误差

任何一项异常 → 停止，回到地面排查。不要"再试一次看看"。

---

## G. 自主飞行（S3 第二阶段）

前置条件：F 阶段全部通过，且 `.ulg` 分析无异常。

- [ ] 先在 **Position 模式**下手动飞一圈，确认位置保持稳定
- [ ] 切 Offboard 前确认 `flight_health.ready_for_offboard == true`
- [ ] 第一次 Offboard 只做最简单的动作：`Takeoff` action 到 5 m，悬停，`Land`
- [ ] 全程手指放在模式开关上，随时准备切回 Position
- [ ] 成功后再逐步加复杂度：Orbit → Revisit → InspectSweep
- [ ] **每增加一个动作，飞一次，下载日志分析一次**

> `Revisit` 动作会让飞机自主下降。第一次测试时把 `descend_to_agl_m` 设成保守值（如 10 m），
> 并确认服务端的安全夹紧逻辑（最低高度限制）真的生效 —— 看 Result 里的 `actual_agl_m`。

---

## H. 落地后（每次飞行都做）

- [ ] 上锁，安全开关锁定，断电
- [ ] 拆桨
- [ ] 电机、电调、电池摸温度，异常发热记录下来
- [ ] **下载 `.ulg` 日志，当场备份**
- [ ] 填写飞行记录（见下方模板）
- [ ] 电池放到存储电压（长期不用时）

### 飞行记录模板

复制到 `flight/logs/YYYY-MM-DD_flight_NN.md`：

```markdown
# 飞行记录 2026-MM-DD #NN

- 场地 / 天气 / 风速：
- 固件版本 / 参数快照版本：
- 本次目的：
- 执行的任务 YAML：
- 飞行时长 / 电池消耗：
- `.ulg` 文件名：
- 结果：成功 / 部分成功 / 中止（原因）
- 异常现象：
- 日志分析发现：
- 下次要改的：
```

**这份记录不是形式主义。** 毕设答辩和论文的「飞行验证」章节，靠的就是这一叠记录 +
`.ulg` 日志。事后补编不出来，而且编的会被看出来。

## I. 紧急情况处置

| 情况 | 动作 |
|---|---|
| 飞机行为异常但可控 | 立刻切 **Position 模式**，手动飞回，降落 |
| 飞机失控但仍在视距内 | 拨 **RTL**。无效则切 Manual 尝试手动降落 |
| 完全失控，朝人群飞 | **立刻切 Manual 并收油门让它掉下来。** 摔机比伤人便宜无限倍 |
| 机载电脑失联（Offboard 中） | 飞控会按 `COM_OBL_RC_ACT` 自动处置。人工确认后切 Position |
| 电池起火 | 远离，用灭火毯或沙覆盖。**不要用水** |
| 桨叶伤人 | 立刻断电，急救，必要时呼叫 120 |
