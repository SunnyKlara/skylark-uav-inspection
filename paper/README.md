## 样式约定

- 数学公式用 `$...$` / `$$...$$`（迁移到 LaTeX/Word 时 1:1 等价）
- 图表占位用 `![标题](figures/fig_xxx.png)`，对应到 `code/paper/figures/`
- 引用格式 `[1]`、`[2]`，参考文献文件按编号顺序维护
- 关键术语首次出现给中英对照：注意力机制（Attention Mechanism）
