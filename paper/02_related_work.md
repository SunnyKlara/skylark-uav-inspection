# 第 2 章 相关理论与研究综述

## 2.1 光伏组件缺陷及其成像原理

### 2.1.1 光伏组件常见缺陷类型

光伏组件由多块单元（cell）经层压封装而成，长期户外运行中会出现多种类型的缺陷。按缺陷成因可分为三类：

**制造缺陷（Manufacturing Defects）**：在生产环节产生，包括栅线断裂（finger interruption）、印刷错误（printing error）、对位错位（dislocation）、烧结不良引起的黑芯（black core）等。这类缺陷在出厂检测阶段即可被发现，但部分隐蔽缺陷会随使用时间显现。

**机械应力缺陷（Mechanical Defects）**：由运输碰撞、冰雹、人员踩踏、热膨胀等机械载荷引发，典型表现为隐裂（crack）、星状裂纹（star crack）、碎片（fragment）、边角损坏（corner defect）等。隐裂可能在初期无明显电学影响，但会随时间扩展并引发热斑。

**电气退化缺陷（Electrical Degradation）**：包括 PID 衰减、短路（short circuit）、二极管失效等。这类缺陷通常表现为电致发光强度的整体性变化。

PVEL-AD 数据集 [9] 涵盖上述三类缺陷的 12 个细分类别，本文按其原始定义保持一致。

### 2.1.2 电致发光（EL）成像原理

电致发光（Electroluminescence, EL）成像是光伏缺陷检测的主流非破坏性手段。其原理是：当光伏组件被施加正向偏置电压时，少数载流子在 P-N 结复合并发射近红外光（中心波长约 1150 nm）。光子发射强度与光生载流子寿命正相关——缺陷区域因载流子复合机制异常表现为低亮度暗区。EL 图像通常需在暗室或夜间拍摄，分辨率受限于近红外 CCD 传感器与组件距离。

无人机搭载 EL 设备的航拍模式具有以下特点：
- **像素尺度**：单组件在 1024×1024 EL 图像中通常占据约 600×600 像素，对应单 cell 约 100×100 像素；
- **小目标占比**：栅线宽度约 50 微米，在 cell 上的投影宽度仅 1–3 像素，属典型小目标；
- **亮度归一化**：不同曝光时间下的图像亮度差异需经预处理消除。

## 2.2 基于深度学习的目标检测

目标检测的任务是在图像中同时定位与分类多个目标实例，其形式化定义为：给定图像 $I \in \mathbb{R}^{H \times W \times 3}$，输出目标集合 $\{(b_i, c_i, s_i)\}_{i=1}^{N}$，其中 $b_i = (x_i, y_i, w_i, h_i)$ 为边界框、$c_i \in \{1, ..., C\}$ 为类别、$s_i \in [0, 1]$ 为置信度。

### 2.2.1 两阶段检测器

两阶段方法以 Faster R-CNN [6] 为代表，先通过区域候选网络（Region Proposal Network, RPN）生成约 2000 个候选区域，再通过 RoI 池化与分类回归头精修。该范式精度高但推理速度慢（典型 5–10 FPS），主要用于精度优先的离线分析。

### 2.2.2 一阶段检测器与 YOLO 系列

一阶段方法将检测建模为单次回归问题，YOLO 系列 [7,8,12,13] 是其代表。YOLO 的核心思想是：

$$P(\text{Object}, \text{Class}_c, b) = f_\theta(I)$$

即由单个网络 $f_\theta$ 直接从输入图像预测多类目标的位置与类别。

**YOLOv8** [15] 引入了无锚框（anchor-free）的解耦检测头与新的损失函数（CIoU + BCE），并提供了 nano 到 extra-large 的全规格模型族。

**YOLOv10** [16] 提出端到端无 NMS 训练（dual label assignment），消除了后处理时延并改善小批量推理表现。

**YOLOv11** [17] 进一步优化了骨干网络（C3k2 模块）、引入 C2PSA 自注意力模块、并增强了高分辨率训练能力。其 nano 版本（约 2.6M 参数，6.5 GFLOPs）在保持高精度的同时具备良好的边缘部署能力，是本文选取的基线。

### 2.2.3 基于 Transformer 的检测器

DETR [18] 首次将 Transformer 引入检测任务，使用基于集合的全局损失消除 NMS。DETR 训练收敛慢、对小目标不友好，后续工作如 Deformable-DETR [39] 通过稀疏注意力改善了上述问题。**RT-DETR** [19] 是百度提出的实时变体，在主干使用混合编码器，达到与 YOLO 系列相当的速度。但 Transformer 类检测器的显存占用较高（如 RT-DETR-l 单批训练显存峰值可达 14 GB+），在 16 GB 显存设备上易触发 OOM，本文将其纳入对比但未列入主要 baseline。

### 2.2.4 检测评价指标

主流检测任务采用 COCO 风格指标：

- **AP（Average Precision）**：在不同召回率下的平均准确率，按 IoU=0.5:0.05:0.95 计算后再平均得到 **mAP@0.5:0.95**；
- **mAP@0.5**：固定 IoU 阈值 0.5 下的 AP，对小数据集与小目标场景更友好；
- **Precision/Recall**：分别衡量预测的准确性与召回完整性；
- **FPS（Frames Per Second）**：在固定输入分辨率下的推理吞吐量；
- **Params / FLOPs**：模型参数量与单次推理浮点运算数，反映模型规模与计算开销。

## 2.3 注意力机制

注意力机制的核心思想是让网络"自适应地决定关注什么"。在 CNN 的特征图 $X \in \mathbb{R}^{C \times H \times W}$ 上，注意力可大致分为通道注意力（关注哪些通道更重要）、空间注意力（关注哪些位置更重要）、以及二者组合。

### 2.3.1 通道注意力：SENet 与 ECA

**SENet** [30] 提出 Squeeze-and-Excitation 模块：

$$z_c = \frac{1}{H \cdot W} \sum_{i=1}^{H} \sum_{j=1}^{W} x_{c,i,j}$$

$$\mathbf{s} = \sigma(W_2 \cdot \delta(W_1 \cdot \mathbf{z}))$$

其中 $\sigma$ 为 sigmoid，$\delta$ 为 ReLU，$W_1$、$W_2$ 为学习参数，输出注意力向量 $\mathbf{s} \in \mathbb{R}^C$ 与原始特征逐通道相乘。

**ECA-Net** [32] 用 1D 卷积近似 SE 中的全连接层，将参数量从 $O(C^2/r)$ 降至 $O(\log C)$，几乎不增加开销即可获得相近效果。

### 2.3.2 通道-空间联合注意力：CBAM

**CBAM**（Convolutional Block Attention Module）[31] 串联通道与空间两路注意力：

$$X' = M_c(X) \otimes X$$
$$X'' = M_s(X') \otimes X'$$

其中：
- 通道注意力 $M_c(X) = \sigma(\text{MLP}(\text{AvgPool}(X)) + \text{MLP}(\text{MaxPool}(X)))$
- 空间注意力 $M_s(X') = \sigma(f^{7\times 7}([\text{AvgPool}(X'); \text{MaxPool}(X')]))$

CBAM 兼具空间定位（"哪里"）与通道判别（"什么"）能力，参数量极小（< 0.1% 主干），适合嵌入轻量级网络。本文选用 CBAM 作为基础注意力模块的依据有三：（1）通道-空间双分支结构与光伏缺陷"特定形态+特定位置"的双重特性匹配；（2）参数量与计算开销可忽略，符合轻量化要求；（3）开源实现稳定，便于复现与对比。

### 2.3.3 高效多尺度注意力：EMA

**EMA**（Efficient Multi-Scale Attention）[34] 通过分组并行的注意力路径融合多尺度上下文，在精度与效率上略优于 CBAM。本文将其作为消融实验中的 CBAM 替代基线，用以验证 CBAM 选择的合理性。

## 2.4 多尺度特征融合

### 2.4.1 FPN 与 PAN-FPN

**FPN**（Feature Pyramid Network）[35] 通过自顶向下路径将深层语义信息逐级注入浅层特征，使每一层级（P3/P4/P5）都同时拥有定位精度与语义信息：

$$P_l = \text{Conv}_{1\times 1}(C_l) + \text{Upsample}(P_{l+1})$$

其中 $C_l$ 为骨干第 $l$ 层输出。FPN 显著提升小目标检测性能，被 RetinaNet、Mask R-CNN 等众多检测器采用。

**PANet（PAN-FPN）**[36] 在 FPN 的自顶向下路径之外，增加自底向上的二次融合路径：

$$N_{l+1} = \text{Conv}_{3\times 3}([\text{DownSample}(N_l); P_{l+1}])$$

形成"自顶向下 + 自底向上"的双向融合。PAN-FPN 是 YOLOv4–YOLOv11 颈部的标准结构。

### 2.4.2 BiFPN

**BiFPN**（Bi-directional Feature Pyramid Network）[37] 进一步将 PAN-FPN 改为可堆叠的双向融合模块，并为每个融合点学习软权重：

$$O = \sum_i \frac{w_i}{\epsilon + \sum_j w_j} \cdot I_i$$

其中 $w_i$ 为可学习的非负权重。BiFPN 可重复堆叠（典型 d=3–7），在 EfficientDet 中被证明对小目标显著有效。

本文模块库实现了简化版 BiFPN（`models/modules/bifpn.py`），但在最终的 yolo11n_full 网络中未启用，原因是：（1）双向融合带来的额外计算开销与轻量化目标存在张力；（2）实际消融发现 CBAM + P2 已能覆盖小目标性能提升的主要收益，BiFPN 的边际收益较小。BiFPN 留作 5.2 节展望部分讨论的可选拓展。

### 2.4.3 小目标检测头：P2 分支

通用 YOLO 检测器输出 P3（步长 8）、P4（步长 16）、P5（步长 32）三个尺度。最浅的 P3 在 640×640 输入下分辨率为 80×80，单个 cell 仅占 8×8 像素，对栅线断裂这类目标已接近临界。

**P2 分支**（步长 4，160×160 分辨率）通过新增一层上采样路径将输出尺度向更精细的方向延伸，使最小可被检出的目标尺寸由约 8 像素降至约 4 像素。P2 增强已在 VisDrone [40]、TinyPerson [41] 等小目标数据集上被验证有效。本文借鉴这一思想为光伏小目标检测设计四尺度（P2/P3/P4/P5）检测头。

## 2.5 模型轻量化与边缘部署

边缘部署是工业落地的最后一公里，本节简述与本文相关的关键技术路线。

**结构层面**：MobileNet 系列 [42] 提出深度可分离卷积，ShuffleNet [43] 引入通道混洗，YOLOv8/v11 nano 版本通过减小通道数（width_multiple）控制参数量。

**精度层面**：FP16 半精度训练（AMP）几乎是无损的精度压缩；INT8 量化（PTQ/QAT）可进一步压缩模型大小至 1/4，但需要校准数据。

**部署运行时**：ONNX Runtime [44] 提供跨平台推理能力，TensorRT [45] 在 NVIDIA GPU 上可获得最优性能。本文实验在第 4 章评估 PyTorch FP32/FP16 与 ONNX Runtime 三种部署形态的精度-速度权衡。

## 2.6 现有方法的局限性分析与本文出发点

通过对上述文献的梳理，可以发现现有面向光伏缺陷检测的工作存在以下不足，构成本文的研究出发点：

| 现有不足 | 本文应对策略 |
|---|---|
| 检测器对小目标缺陷召回率不足 | 引入 P2 高分辨率检测分支 |
| 单点注意力的判别能力有限 | 在骨干 P3/P4/P5 三层级叠加 CBAM |
| 长尾分布下稀有类别被忽略 | 数据增强 + 类别均衡权重 + 负样本利用 |
| 轻量化与精度难以兼顾 | 选定 YOLOv11n 为基线，所有改进保持参数量不超过 baseline 的 2 倍 |
| 缺乏系统性鲁棒性评估 | 设计 6 种扰动 × 3 强度的鲁棒性基准 |
| 部署可行性验证不足 | 提供 PyTorch / ONNX 三种部署形态对比 |

## 2.7 本章小结

本章首先介绍了光伏组件常见缺陷与 EL 成像原理，明确了无人机视角下小目标检测的物理特性；接着梳理了一阶段、两阶段、Transformer 三类检测器的发展脉络，论证了 YOLOv11n 作为基线的合理性；继而综述了 SENet、CBAM、EMA 等注意力机制与 FPN、PAN-FPN、BiFPN 等多尺度融合技术，为本文方法设计提供了理论依据；最后从模型轻量化与边缘部署的角度补充了工业落地相关技术。综合分析显示，现有方法在小目标召回、长尾分布、负样本利用、系统性评估等方面存在不足，本文的三项创新点直接对应这些不足。
