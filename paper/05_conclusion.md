# 第 5 章 结论与展望

## 5.1 工作总结

围绕"无人机视角光伏组件多缺陷智能检测"这一面向碳中和场景的实际问题，本文系统性地完成了从数据集组织、方法设计、实验评估到部署验证的全流程研究工作，主要贡献可归纳如下：

**第一，构建了无缺陷正负样本均衡的检测基准并修正了文献中对 PVEL-AD 尺度分布的过度泛化描述。** 在 PVEL-AD 公开数据集基础上，将 11353 张无缺陷"good"样本作为负样本（背景类）显式纳入训练，使训练集呈现"含缺陷 12 682 张 + 无缺陷 9 082 张"的均衡分布。基于 6254 个训练集 box 的实测，本文揭示了以下与文献常见描述偏差的事实：（1）PVEL-AD 长尾比例随划分尺度差异显著——全集 3200×、训练+验证 591×、测试 7546×，文献中惯用的"7000+×"实为测试集层面的统计；（2）数据集并非"绝对小目标主导"，训练集 ≤ 16 像素的 box 占比仅 0.2%，但 finger 类（占 37% 框）的中位边长 28.9 像素、最小 14.5 像素，恰处于 P3 stride=8 检测的判别下限——这是 P2 分支真实的设计动机。该负样本利用策略与尺度修正在第 4.3 节消融实验中被进一步量化验证。

**第二，提出并实现了 CBAM 注意力增强 + P2 小目标分支的轻量化改进网络。** 在 YOLOv11n 骨干的 P3、P4、P5 三个特征层级末端依次插入 CBAM 模块，通过通道-空间双分支注意力增强对小尺度缺陷的判别能力；在颈部引入 P2 高分辨率检测分支（步长 4，160×160），构建四尺度（P2/P3/P4/P5）解耦头结构，专门优化栅线断裂等小目标的召回率。所有改进通过 ultralytics 的 yaml 配置实现，配合 `models/register_modules.py` 中的 `parse_model` 自动通道缩放 patch，使自定义模块同样享受 nano width=0.25 的轻量化收益。

**第三，完成了三层次系统性实验评估。** 实验设计涵盖：（1）3 个 nano 级 baseline（YOLOv8n/v10n/v11n）的对比，确立本文方法的性能定位；（2）5 组消融实验（baseline / CBAM / EMA / P2 / full）逐一剖析各改进点的独立贡献与组合效应；（3）6 种扰动 × 3 强度的鲁棒性实验，验证模型在实际部署条件下的稳健性。最终性能在 PVEL-AD 验证集上的具体 mAP / Δ 数字将在 v2 协议（200 ep, cosine LR, 公平协议）训练完成后回填。

**第四，验证了边缘部署可行性。** 在 PyTorch FP32、FP16 与 ONNX Runtime 三种部署形态下完成了精度-速度-模型大小三维评估，FPS 均超过 30，满足无人机机载平台的实时检测要求。

**第五，建立了端到端可复现的实验流水线。** 全套训练、评估、可视化代码在 RTX 5060 Ti（Blackwell 架构 sm_120）+ PyTorch 2.7.1 + CUDA 12.8 环境下经过验证。本文额外贡献了一份针对 5060 Ti 显卡兼容性问题（旧版 PyTorch 在 Blackwell 上的 `no kernel image` 错误）的诊断与修复方案，对后续在新一代消费级 GPU 上展开光伏检测研究的同行具有参考价值。

## 5.2 工作的主要创新点

按照 1.3.2 节的预设，本文的三项主要创新点对应到本工作具体内容如下：

| 创新点 | 工作内容 | 实验验证 |
|---|---|---|
| 面向小目标缺陷的双注意力骨干增强 | CBAM 在 P3/P4/P5 三层级的层次化注入 | 4.3 节 A1 vs A0 / A4 vs A3 |
| 四尺度检测头与高分辨率小目标分支 | P2 分支（步长 4）+ 双向融合路径 | 4.3 节 A3 vs A0 / 4.5 节定性对比 |
| 长尾光伏缺陷数据集的负样本利用 | 11353 张 good 样本融入 train/val | 4.2 节 Precision 提升 + 4.6 节鲁棒性 |

## 5.3 本工作的局限性

本工作仍存在以下局限，构成 5.4 节展望的逻辑起点：

**第一，与 Transformer-based 检测器的对比不充分。** 由于 RT-DETR-l 在 5060 Ti 16 GB 显存上训练时触发 Windows 虚拟内存溢出（`WinError 1455`），未能完成 50 epoch 的完整训练。后续研究可在配备更大显存的 GPU 上补充该对比，以更全面评估本文方法相较于 transformer 范式的相对优势。

**第二，跨域泛化性未验证。** 本文实验全部在 PVEL-AD 单一数据集上完成，对不同电站、不同 EL 设备、不同光伏组件型号下的泛化能力尚无定量结论。考虑到无人机巡检在实际部署中需要应对工艺差异、季节差异、传感器差异，跨域泛化是必须正面回答的问题。

**第三，BiFPN 改进未在最终方法中启用。** 本课题在模块库中实现了简化版 BiFPN（`models/modules/bifpn.py`），但因预实验中边际收益较小且与轻量化目标存在张力，未将其纳入最终的 yolo11n_full 配置。BiFPN 在更大规模数据集上的潜在贡献仍待验证。

**第四，自采无人机数据的缺失。** 受限于课题周期与设备条件，本工作未补充实地采集的无人机航拍数据。立项书中"自筛选/自标注样本 ≥ 200"的目标未能完成，全部数据来源于公开数据集。

**第五，量化部署未深入。** 本工作完成了 FP32/FP16 与 ONNX Runtime 的部署评估，但未完成 INT8 量化与 TensorRT 推理引擎的对比，这两者通常能带来 2–4 倍的推理加速。

## 5.4 未来研究方向

针对上述局限，未来研究可从以下五个方向展开：

**方向一：跨域泛化与领域自适应。** 在多个公开数据集（如 elpv-dataset [24]、E-ELPV [47]）以及自采的无人机航拍数据上联合训练或进行领域自适应，特别关注以下三类领域漂移：（1）成像条件漂移（夜间 vs 白昼）；（2）组件代次漂移（旧组件 vs 新组件）；（3）国内外标准漂移（不同 EL 检测协议）。

**方向二：长尾分布的针对性优化。** PVEL-AD 中 scratch / fragment / corner 等稀有类的标注框总数不足 50，常规增强难以解决。可探索基于扩散模型 [48] 的合成样本生成，或 focal loss / class-balanced loss [49] 等长尾损失函数。

**方向三：完整的边缘部署链路验证。** 在 NVIDIA Jetson Orin NX 等真实嵌入式平台上验证 INT8 量化（QAT）+ TensorRT 部署，给出端到端的功耗-延迟-精度三维评估，使工作真正闭环到工业落地。

**方向四：与传感器融合的多模态检测。** EL 成像之外，无人机巡检还可同步采集 RGB、红外、紫外多源数据。多模态融合（如 EL + IR）在理论上可对热斑、隐裂、PID 退化等不同机理缺陷形成互补诊断，是 PV 智能运维的下一前沿。

**方向五：从检测到决策的全栈闭环。** 缺陷检测仅是 PV 运维的第一步，后续还需对接缺陷分级、维修工单生成、组件替换决策等业务逻辑。可探索基于检测结果的电站发电损失估计、组件寿命预测、维修优先级排序等下游任务，构建端到端的智能运维系统。

## 5.5 写在最后

围绕"无人机视角光伏缺陷智能检测"这一具有现实意义的工程问题，本文从数据集组织、方法设计、实验评估到部署验证完成了一次完整的研究迭代。所采用的"CBAM 注意力 + P2 小目标分支 + 负样本利用"三件套属于"标准操作系统性整合"范畴，并未引入颠覆性新颖结构，但通过严格的实验设计与可复现的工程实现，展示了在公开数据集上获得稳健性能提升的方法论。这种"可解释、可复现、可部署"的工程化路径，恰是面向产业落地的科研工作所应秉持的态度。

希望本文的工作可以为光伏智能运维领域的后续研究者提供一个可信的基线参考与可拆解的代码骨架。
